# Folia 调度与生命周期修复

适用补丁：1.21.11 / 26.1.2 / 26.2 的 tcp.2.2，以及 26.3 的 tcp.3.1。

## 修复内容

- Paper 路由通过平台全局调度器启动，避免 Folia 拒绝 MinecraftServer.execute。
- 路由提交失败、任务异常、停服时均释放排队标记，允许后续更新恢复。
- 玩家状态、位置、权限、可见性在各自实体线程采样，使用不可变快照计算路由。
- 实体已移除、任务拒绝、采样异常会完成空快照；缺失回调在 1.5 秒后超时，不复用旧玩家状态。迟到任务不再次采样或发布。
- 玩家重连时核对实例，避免将旧连接快照发布给同 UUID 的新连接。
- 收包、权限检查、踢出、初始状态同步及发包转到玩家实体调度器；跨线程状态字段使用可见性保证。
- Paper 只在本插件禁用时关闭语音服务器；发包后释放临时网络缓冲区。
- Bukkit 路由提交失败也会恢复排队标记；Folia 加载通用 Bukkit 包时给出明确提示并安全停用，请改用匹配版本的 Paper 包。

## Folia 后端配置

安装与游戏版本匹配的 voicechat-paper JAR。使用此分支配套的 Velocity/Bungee 语音代理；后端配置应包括：

    # 代理处理语音传输；Folia 后端必须使用代理模式
    proxy_mode=true
    # 允许线程化服务端支持
    threaded_server_support=true

修改后完整重启。26.3 保留代理自动检测；其他版本仍需显式设置 proxy_mode。
旧分支保留 TCP 1021 协议，26.3 保留 TCP 1021 + 原版 UDP 20；此补丁不改变协议。
Folia 上需要后端处理原始音频的第三方扩展尚不支持，插件会明确提示并禁用相关语音路由。

## 验证范围

GitHub Actions 编译各平台；tests/folia/run.py 提取实际生产调度和批处理方法，检查拒绝提交、退休回调、超时、迟到任务、停服、异常恢复和批次互斥。
现有传输及对应分支其他回归测试继续运行。回归使用调度器替身，不能替代真实 Folia 联机、跨区域移动、跨服切换与音频验收。
